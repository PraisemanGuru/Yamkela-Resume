# Yamkela-Resume
My Updated Resume
# Features
🎯 Fixed Navigation Bar - Smooth scrolling navigation to each section

👤 Professional Header - Clean introduction with role and location

📊 Skills Section - Organized display of technical competencies

💼 Experience Timeline - Professional experience with descriptions

🎓 Education Section - Academic qualifications

📞 Contact Information - Professional contact details

📱 Responsive Design - Works across different screen sizes
# Technologies Used
HTML5 - Semantic markup

CSS3 - Custom styling with modern layout techniques

Font Awesome - Icon library for visual enhancements

Google Fonts - Poppins font family
# 📁 File Structure
project/
├── index.html      # Main HTML file
└── resume.css      # Stylesheet (referenced in HTML)
# 🚀 Sections
About - Professional summary and location

Skills - Technical competencies categorized by domain:

Backend Development (C#, .NET, SQL, etc.)

Frontend & Web Technologies (JavaScript, React, Angular, etc.)

Tools & Practices (Git, CI/CD, Cloud platforms, etc.)

Experience - Professional work history with role descriptions

Education - Academic background

Contact - Email and phone information
# 🎨 Design Highlights
Minimalist professional color scheme

Card-based layout for content sections

Hover effects on cards and navigation items

Clean typography with good readability

Responsive grid layouts using CSS Grid
# 🔧 Setup & Usage
Clone or download the HTML file

Ensure resume.css is in the same directory

Open index.html in any modern web browser

No build steps or dependencies required
# 📱 Responsive Breakpoints
Desktop - Full-width layout with max-width container

Tablet - Adjusted spacing and grid layouts

Mobile - Stacked layout with adjusted typography
# 💻 Browser Support
Compatible with all modern browsers including:

Chrome

Firefox

Safari

Edge
